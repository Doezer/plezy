## 2025-05-22 - [Optimizing Scroll Performance and Rebuild Efficiency]
**Learning:** Calling `setState` inside a `ScrollController` listener causes the entire widget and its subtree to rebuild on every frame while scrolling. Using `ListenableBuilder` or `AnimatedBuilder` with the `ScrollController` as the listenable allows for localized rebuilds of only the widgets that depend on the scroll offset. Additionally, providing `itemExtent` to `ListView.builder` for lists with fixed-size items significantly reduces layout overhead by skipping child measurement. Finally, using specific `MediaQuery` selectors (like `sizeOf`) instead of the generic `of(context)` prevents unnecessary rebuilds when unrelated properties of `MediaQueryData` change.
**Action:** Always prefer localized rebuilds for scroll-linked effects, provide `itemExtent` for fixed-size lists, and use specific `MediaQuery` selectors for property access.
