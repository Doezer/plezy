## 2025-05-14 - Specialized MediaQuery Selectors and List itemExtent
**Learning:** In modern Flutter (3.10+), using specialized MediaQuery selectors like `MediaQuery.sizeOf(context)` or `MediaQuery.paddingOf(context)` is significantly more efficient than `MediaQuery.of(context)`. The latter causes a rebuild whenever *any* property of `MediaQueryData` changes (e.g., keyboard visibility, text scale), whereas specialized selectors only trigger rebuilds for the specific property they watch. Additionally, `itemExtent` in `ListView` is a powerful optimization for lists with uniform child sizes, as it allows the framework to skip child measurement.
**Action:** Always prefer specialized MediaQuery selectors over `MediaQuery.of(context)`. Use `context.select` for Provider to further narrow rebuild triggers. Provide `itemExtent` for Lists when children have fixed dimensions.
